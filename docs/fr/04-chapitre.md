# 4. Gouvernance et limites

Governor et guardian n’ont pas le même pouvoir : le premier administre les paramètres, le second intervient en urgence. Les risques résident dans les oracles, les upgrades et les hypothèses de liquidité.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
